Level 5: mark which products are good results for each test query. Back to search

How to label

  • Ask yourself: would I be happy to see this product in the top results for this search? Yes = Relevant, No = Not relevant.
  • Judge each product on its own. Don't think about which search method found it (the page hides that on purpose, and the order is shuffled).
  • If you are not sure, choose what most shoppers would think. Your labels are saved as soon as you click.
